# Rhapsody Hub - Gamification Protocol

O **Rhapsody Hub** é um aplicativo modular de gamificação projetado para transformar engajamento em recompensas reais. Este projeto é um protótipo funcional (mockup) focado na experiência do usuário, integrando missões de parceiros, mercado preditivo e um dashboard de recompensas.

## 🚀 Funcionalidades

- **Loop Diário de Check-in**: Sistema de streak para incentivar o acesso diário e ganho de pontos.
- **Central de Missões**: Integração com parceiros (ex: MusicPlayce) para realização de tarefas externas e ganho de recompensas no Hub.
- **Mercado Preditivo (Points-only)**: Participe de previsões sobre música, cultura e crypto usando seus pontos acumulados.
- **Dashboard de Perfil**: Acompanhamento de saldo, XP, nível e monitoramento de pontos a expirar.
- **Loja (Preview)**: Catálogo futuro para troca de pontos por boosters, badges e ativos digitais.

## 🛠️ Tecnologias Utilizadas

- **Frontend**: React + Vite
- **Estilização**: Tailwind CSS v4
- **Estado Global**: Zustand
- **Componentes**: Shadcn/UI + Lucide Icons
- **Animações**: Framer Motion
- **Roteamento**: Wouter

## 📦 Como rodar o projeto

1. Instale as dependências:
   ```bash
   npm install
   ```

2. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev:client
   ```

3. Acesse o projeto em `http://localhost:5000`
